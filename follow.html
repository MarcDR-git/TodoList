Bienvenido a la guía

ToListEl es una aplicación orientada a la administración de tareas y creación de lista de la vida cotidiana. No necesita conexión a internet ni expone datos personales, con el objetivo de dar una herramienta que se pueda usar en cualquier situación.

📋
To-Do List

▼

Aquí puedes organizar tus listas de tareas por categorías. Cada lista es un contenedor independiente.

  • Crear Lista: Usa el botón "+" para añadir una nueva categoría (ej. "Trabajo", "Super").
  • Gestionar: Dentro de cada lista, puedes añadir elementos específicos.
  • Eliminar: Desliza o usa el icono de papelera para borrar listas completas.

✅
Tareas

▼

Gestión detallada de cada actividad pendiente.

  • Vincular: Puedes conectar una tarea con un elemento de tus listas To-Do.
  • Prioridad: Define qué tareas son urgentes.
  • Estado: Marca como "Hecha" o "Pendiente" para ver el progreso en la barra visual.

📅
Calendario

▼

Visualiza tus tareas de forma temporal para no perder ningún plazo.

  • Vista Mensual: Los días con tareas aparecen resaltados con un punto o color morado.
  • Selección: Toca un día para ver la lista de tareas específicas programadas para esa fecha.
  • Navegación: Cambia de mes o año usando los selectores superiores.

📌
Mensajes Fijados

▼

Recordatorios importantes que aparecen directamente en tu pantalla de Inicio.

  • Fijar: Crea un mensaje y asígnale una tarea para que sea lo primero que veas al abrir la app.
  • Acceso Rápido: Tocar el mensaje te llevará directamente a la tarea vinculada.

🖼️
Imágenes y Links

▼

Haz que tus listas sean más visuales y útiles.

  • Imágenes: Al editar un ítem, pega la URL de una imagen para ver una previsualización en la tarjeta.
  • Enlaces: Añade links externos (como recetas o documentos) para abrir directamente desde la tarea.

💾
Importar y Exportar

▼

No pierdas nunca tu información o compártela con otros.

  • Exportar: Descarga tus listas en formato JSON para tener una copia de seguridad.
  • Importar: Sube un archivo JSON de ToListEI para restaurar tus tareas en cualquier dispositivo.
